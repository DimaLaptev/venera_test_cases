# Кодификатор ВТБ СД

Вход: текст **«Раздел счёта депo»** (col 2 выписки, строки 13+).

| Подстрока в разделе | P Состояние | M ENC | N Вид учёта |
|---------------------|-------------|-------|-------------|
| `Закладные обездвижены. Включены в РИП` | На хранении | ENC2 | Депозитарный учет ДЗ |
| `Свободное обращение` без `(Электронное хранилище)` | На хранении | ENC2 | Депозитарный учет ДЗ |
| `Временное изъятие закладных` без `(Электронное хранилище)` | Временное снятие ДЗ | ENC2 | Депозитарный учет ДЗ |
| `Свободное обращение` + `(Электронное хранилище)` | На хранении | ENC3 | Депозитарный учет ЭЗ |
| `Блокировано до выпуска` + `(Электронное хранилище)` | Временное снятие ЭЗ | ENC3 | Депозитарный учет ЭЗ |
| `Электронные закладные. Включены в РИП` | На хранении | ENC3 | Депозитарный учет ЭЗ |

Fallback: `(Электронное хранилище)` → ENC3/ЭЗ, иначе ENC2/ДЗ.

Реализация: [`src/references/vtb_codifier.py`](../src/references/vtb_codifier.py).
