# SVOD DEPO — спецификация

Pipeline собирает два файла из `source/` по матрице «Источники»:

| Файл | Листы |
|------|-------|
| `СВОД_поДЕПО.xlsx` | `ДОМ ИА`, `ДОМ ИА-Оригинатор ВТБ`, `ДОМ ИА-Оригинатор Сбер` |
| `СВОД_поДЕПО_ДОМ.xlsx` | `ДОМ_Оригинатор ДОМ_РезСервис` |

Маршрутизация строк на лист: **Справочник 1**, col K «Раздел КП для Свода депo» по счёту депo (col E).

## Колонки выхода

**26 колонок A–Z**, шапка строка 5, данные с 6. Пустой столбец O отсутствует.

## Источники

| Обозначение | Файл/каталог |
|-------------|--------------|
| Обозначение | Файл/каталог |
|-------------|--------------|
| СДПМ (ИА) | `DEPO_IA.xlsx` — листы `GPB`, `REGION`, `VTBSD`, `RSD_XLS` → **СВОД_поДЕПО**; либо прошлый `СВОД_поДЕПО.xlsx` (`--prior-from-svod`) |
| СДПМ (ДОМ) | `DEPO_DOM.xlsx` — листы `GPB`, `RSD_MSG`, `REGION`, `VTBSD` → **СВОД_поДЕПО_ДОМ**; либо прошлый `СВОД_поДЕПО_ДОМ.xlsx` (`--prior-from-svod`) |
| СС | `SPRAV/Справочник.xlsx` лист «Таблица сопоставления 1» |
| СМХ | `SPRAV/Справочник.xlsx` лист «Таблица сопоставления 2» |
| ДО ГПБ | `GPB/R_*.MSG` |
| ДО РСД | `RSD_MSG/R_*.MSG`, `RSD_EXL/` (выписка **R-05**, zip распаковывается) |
| ДО REGION | `REGION/` (zip → xml формат 1 + VL*.XLS формат 2) |
| ДО ВТБ | `VTBSD/*.xlsx` |

## Ключи lookup

- A, B, I, J, T, U, W, X, Y ← отчёт пред. месяца по НГРИ (K): **DEPO_IA** для листов СВОД_поДЕПО, **DEPO_DOM** для СВОД_пoДЕПО_ДОМ
- C, D, M, N, Q, R ← Справочник 1 по счёту депo (E)
- **Лист свода** ← Справочник 1 col K «Раздел КП для Свода депo» по счёту депo (E)
- S ← Справочник 2: «Город - место хранения» по «Номер раздела (текст)» = col F; для **REGION/VTB** — по первой строке col «Депозитарий» с «Регион»/«ВТБ»
- V ← `Депозитарий & "_" & Счет_депo`
- H = 1; L, Z = null; Y = имя файла
- **O (Состояние)** для REGION: из **формата 2** (`VL####.XLS`, колонка A), подстановка по НГРИ для строк формата 1.
- **T (Дата погашения)**: формат **ДД.ММ.ГГГГ**
