# GPB R_102_*.MSG (`ReportType:REMAINDERS`)

Условие: **A8 пуста**, данные с **строки 9**, разделитель `;`, **10 полей**.

Пример: `102;10934;1;3;1;98040.000;102080004;ZKL102080004;26-26-28/005/2010-124;На хранении`

| № (0-based) | → выход |
|-------------|---------|
| 1 | **E** Счет депo |
| 2 | **F** Раздел счета депo |
| 8 | **K** НГРИ в депo |
| 9 | **O** Состояние |

Поля 0, 3–7 — служебные.

---

# RSD R_*.MSG (`ReportType:R`)

Условие: **A7 пуста**, данные с **строки 8**, **6 полей**.

Пример: `ПАО ДОМ.РФ;000300008201;100014;3477587;1;53-53-11/083/2011-061`

| № | → выход |
|---|---------|
| 2 | **E** |
| 3 | **F** |
| 6 | **K** |

**O** = константа `На хранении`.

# RSD R-05 xlsx (выписка по счёту депo)

Каталог `RSD_EXL/`, архивы `R-05_*.ZIP` → xlsx «ВЫПИСКА ПО СЧЕТУ ДЕПО».

| Поле в таблице остатков | → выход |
|-------------------------|---------|
| Счёт депo (шапка) | **E** |
| «Номер раздела счета депo» — **первый токен до пробела** (`260000 - …` → `260000`) | **F** |
| «Гос. рег. № выпуска» | **K** |

Парсинг **останавливается** на первой полностью пустой строке таблицы (после данных) или при строке с «Исполнитель» / «Ответственное лицо».

**O** = константа `На хранении`.

# REGION / VTB

- **REGION формат 1:** `[VL0032][][IS....].xml` — **F** = `DivisionName` **без преобразований**.
- **REGION формат 2:** `VL0089.XLS` — «Отчет об остатках»; **O** из col A, B НГРИ, E КД, H раздел; счёт из имени файла.
- **REGION legacy:** balance 40-col + Region2 — **F** = `DivisionName` as-is.
- **VTB:** **F** ← col «Раздел места хранения» (col 4), **целиком**; **J** ← col «Номер кредитного договора» (col 11); кодификатор ENC/N — по col «Раздел счёта депо» (col 2).
